## Description
A Python weather application that fetches and displays real-time weather information (temperature, condition, humidity, wind speed) for any given city using the OpenWeatherMap API.

## Features
- Real-time weather data retrieval via REST API
- Displays temperatures in both Celsius and Fahrenheit
- Input validation and network/city error handling
- Dual mode interface: Desktop GUI (Tkinter) and Terminal (CLI)
