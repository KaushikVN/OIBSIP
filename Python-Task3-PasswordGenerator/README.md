# Python Task 3: Random Password Generator

**Track:** Python Programming  
**Organization:** Oasis Infobyte  
**Author:** Kaushik V N  

## Description
A cryptographically secure random password generator built using Python's `secrets` module. Supports custom length, multiple character sets, strength feedback, and one-click clipboard copying.

## Features
- Custom rules: uppercase, lowercase, numbers, symbols, ambiguous filter
- Cryptographically secure randomness using Python `secrets`
- Password strength evaluation (Weak, Medium, Strong)
- Dual mode interface: Desktop GUI (Tkinter) and Terminal (CLI)
- Single-click clipboard copy feature

## How to Run
Run GUI Mode:
python KaushikVN_Task3.py

Run CLI Mode:
python KaushikVN_Task3.py --cli
