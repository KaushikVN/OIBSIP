## Description
A Body Mass Index (BMI) calculator that calculates BMI using metric units and categorizes the result into standard health classifications.

## Features
- Calculates BMI: BMI = weight / (height^2)
- Classifies results into Underweight, Normal weight, Overweight, and Obese
- Input validation to handle negative values and invalid characters
- Dual mode support for GUI and CLI

## Usage
Run GUI:
python KaushikVN_Task2.py

Run CLI:
python KaushikVN_Task2.py --cli
